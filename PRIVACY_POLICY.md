# Privacy Policy / プライバシーポリシー

Last updated: 2025-02-01

---

## English

### Overview

Page to Calendar ("the Extension") is a browser extension that extracts event information from web pages and helps users add them to Google Calendar. This privacy policy explains how we collect, use, and protect your data.

### Data We Collect

#### 1. API Keys
- **What**: Claude API key or Gemini API key that you provide
- **Purpose**: To authenticate requests to AI services for extracting event information
- **Storage**: Stored locally in your browser using Chrome's storage API
- **Sharing**: Never shared with third parties; only sent to the respective AI service (Anthropic or Google) when you click "Extract Info"

#### 2. Web Page Content
- **What**: Title, URL, body text, OGP metadata, and structured data (JSON-LD) of the current web page
- **Purpose**: To extract event information (title, dates, location, description)
- **Storage**: Not stored; processed only in memory during extraction
- **Sharing**: Sent to Claude API (Anthropic) or Gemini API (Google) only when you click "Extract Info"

#### 3. User Preferences
- **What**: Selected AI provider preference
- **Purpose**: To remember your preferred AI service
- **Storage**: Stored locally in your browser
- **Sharing**: Never shared

### Data We Do NOT Collect

- Personal identification information
- Email addresses
- Browsing history
- Location data
- Financial information
- Usage analytics or telemetry

### Third-Party Services

When you use this extension, web page content is sent to one of the following services based on your selection:

- **Claude API (Anthropic)**: [Anthropic Privacy Policy](https://www.anthropic.com/privacy)
- **Gemini API (Google)**: [Google Privacy Policy](https://policies.google.com/privacy)

We recommend reviewing their privacy policies to understand how they handle data.

### Data Security

- All API keys are stored locally in your browser and are never transmitted to our servers
- Communication with AI APIs uses HTTPS encryption
- We do not operate any servers; all processing happens locally in your browser

### Your Rights

- You can delete your stored API keys at any time through Chrome's extension settings
- You can uninstall the extension to remove all locally stored data
- No account creation is required to use this extension

### Changes to This Policy

We may update this privacy policy from time to time. We will notify users of any material changes by updating the "Last updated" date.

### Contact

If you have questions about this privacy policy, please open an issue on our GitHub repository.

## 日本語

### 概要

Page to Calendar（以下「本拡張機能」）は、ウェブページからイベント情報を抽出し、Googleカレンダーへの登録を支援するブラウザ拡張機能です。このプライバシーポリシーでは、データの収集、使用、保護について説明します。

### 収集するデータ

#### 1. APIキー
- **内容**: ユーザーが入力するClaude APIキーまたはGemini APIキー
- **目的**: イベント情報抽出のためのAIサービスへの認証
- **保存場所**: ChromeのストレージAPIを使用してブラウザ内にローカル保存
- **共有**: 第三者とは共有しません。「情報を抽出」ボタンをクリックした時のみ、該当するAIサービス（AnthropicまたはGoogle）に送信されます

#### 2. ウェブページの内容
- **内容**: 現在表示中のウェブページのタイトル、URL、本文テキスト、OGPメタデータ、構造化データ（JSON-LD）
- **目的**: イベント情報（タイトル、日付、場所、説明）の抽出
- **保存場所**: 保存しません。抽出処理中のみメモリ上で処理されます
- **共有**: 「情報を抽出」ボタンをクリックした時のみ、Claude API（Anthropic）またはGemini API（Google）に送信されます

#### 3. ユーザー設定
- **内容**: 選択したAIプロバイダーの設定
- **目的**: 優先するAIサービスを記憶するため
- **保存場所**: ブラウザ内にローカル保存
- **共有**: 共有しません

### 収集しないデータ

- 個人を特定できる情報
- メールアドレス
- 閲覧履歴
- 位置情報
- 金融情報
- 利用統計やテレメトリ

### サードパーティサービス

本拡張機能を使用すると、選択に基づいて以下のいずれかのサービスにウェブページの内容が送信されます：

- **Claude API（Anthropic）**: [Anthropicプライバシーポリシー](https://www.anthropic.com/privacy)
- **Gemini API（Google）**: [Googleプライバシーポリシー](https://policies.google.com/privacy)

これらのサービスがデータをどのように扱うかについては、各社のプライバシーポリシーをご確認ください。

### データセキュリティ

- すべてのAPIキーはブラウザ内にローカル保存され、当方のサーバーには送信されません
- AIAPIとの通信にはHTTPS暗号化を使用しています
- 当方はサーバーを運用していません。すべての処理はブラウザ内でローカルに行われます

### ユーザーの権利

- Chromeの拡張機能設定から、保存されたAPIキーをいつでも削除できます
- 拡張機能をアンインストールすると、ローカルに保存されたすべてのデータが削除されます
- 本拡張機能の使用にアカウント作成は不要です

### ポリシーの変更

本プライバシーポリシーは随時更新される場合があります。重要な変更がある場合は、「最終更新日」を更新してお知らせします。

### お問い合わせ

本プライバシーポリシーについてご質問がある場合は、GitHubリポジトリでissueを作成してください。
